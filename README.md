# Exploratory-Data-Analysis-
Objective
To analyze a dataset and identify trends, patterns, missing values, duplicates, and outliers.

Tools Used
Python
Pandas
NumPy
Matplotlib
Seaborn
SciPy
Steps
Load the dataset.
Explore rows, columns, and data types.
Check missing values and duplicates.
Generate histograms and correlation heatmaps.
Test hypotheses and summarize findings.
How to Run
Install the required libraries:

pip install -r requirements.txt

Run the program:

python eda_analysis.py# EDA-Project
